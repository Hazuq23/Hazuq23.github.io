# Muhammad Haziq Munir — Engineering Portfolio

A responsive static portfolio website built from the latest master résumé and project photos.

## Preview locally

1. Keep `index.html`, `styles.css`, `script.js`, and the `assets` folder together.
2. Double-click `index.html` to open it in a browser.

## Publish with GitHub Pages

1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload everything inside this folder to the root of the repository.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, and choose `/(root)`.
5. Save and wait for GitHub to publish the site.

No résumé PDF is included or linked, so the portfolio can be used with job-specific résumés.
